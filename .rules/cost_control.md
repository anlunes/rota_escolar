\# Cost Control Rules



\- Prioritize low token usage

\- Prefer lightweight reasoning

\- Avoid broad project scans

\- Reuse existing memory/context

\- Keep responses short

\- Avoid repeated analysis

\- Do not generate unnecessary explanations

\- Prefer minimal execution scope

\- One task at a time

\- Escalate complexity only when necessary



\## File Safety



\- Never modify files without explicit request

\- Never rewrite entire files unnecessarily

\- Explain impacted files before execution

\- Prefer minimal patches



\## Execution



\- Think before acting

\- Understand before modifying

\- Stop when uncertain

\- Never assume requirements
